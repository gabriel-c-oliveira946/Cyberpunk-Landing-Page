# Cyberpunk Landing Page

**🌍 [Acesso ao site](https://cyberpunkpage.vercel.app)** 

## Sobre o Projeto
Esta é uma página web temática desenvolvida com estética **Cyberpunk**, criada exclusivamente com HTML5 e CSS3 puros. O objetivo principal do projeto foi a aplicação de variáveis de cor (`:root`), estruturação semântica e estilização avançada (sombras, brilhos e efeitos neon) sem o uso de frameworks externos.

Atividade desenvolvida para o curso técnico em **Desenvolvimento de Sistemas** do **SENAI Dendezeiros**.

## Tecnologias Utilizadas
- **HTML5:** Estrutura semântica e incorporação de mídia (iframe do YouTube).
- **CSS3:** Efeitos visuais (`box-shadow`, `text-shadow`), variáveis globais (`:root`), transições (`hover`) e layout responsivo adaptado para múltiplas resoluções.
- *Nota:* Projeto construído sem Bootstrap, Tailwind, Flexbox ou CSS Grid, respeitando as restrições da atividade prática.
